# 装机清单：从这台 Windows 到手机里能用

> 全程不需要 Mac、不需要付费开发者账号。总耗时约 30 分钟，其中云构建那 8 分钟你只需要等。

## 先确认三件事

- [ ] iPhone 系统版本：设置 → 通用 → 关于本机。**iOS 16 及以上**要额外打开「开发者模式」（第 4 步会讲）
- [ ] 一根能连电脑的**数据线**（要能传数据，不是只能充电的那种）
- [ ] 一个 **Apple ID**（免费账号就行，不要求开发者账号）

---

## 第 1 步：把代码推到 GitHub（约 3 分钟）

本地仓库已经初始化好并提交完毕，你只需要建一个空仓库、把地址接上、推一次。

1. 打开 https://github.com/new
   - Repository name 填 `savings-tracker`
   - 选 **Private**（私有，别人看不到）
   - **不要**勾 Add a README / .gitignore / license（要空仓库）
   - 点 Create repository
2. 回到这台电脑，打开 PowerShell（**新开一个窗口**，这样 PATH 里的 git 才生效），执行：

```powershell
cd C:\Users\Admin1\Doubao\chats\2026-11-10\new-chat-7\savings_tracker
git remote add origin https://github.com/你的用户名/savings-tracker.git
git push -u origin main
```

3. 第一次推送会弹浏览器让你登录 GitHub，登录并授权即可。

> 如果 `git` 提示找不到命令：关掉 PowerShell 重开一个。还不行就临时执行
> `$env:Path = "C:\Users\Admin1\dev\git\cmd;" + $env:Path` 再试。

---

## 第 2 步：Codemagic 云端出安装包（约 10 分钟，其中 8 分钟是等待）

这台 Windows 装不了 Xcode，所以让云端 Mac 帮你编译。

1. 打开 https://codemagic.io ，用 **GitHub 账号**登录（不要用邮箱注册，否则看不到仓库）
2. 点 **Add application** → 选 `savings-tracker` → 项目类型选 **Flutter**
   - 它会自动识别仓库里的 `codemagic.yaml`
3. 左侧 workflow 选 **`ios-personal`** → 点 **Start new build**
4. 等 5~10 分钟，状态变成绿色的 ✅ 后，在右上角 **Artifacts** 里下载 **`SavingsTracker.ipa`**
5. 把下下来的 ipa 放到一个好找的位置，比如桌面

> 免费额度每月 500 分钟，一次构建只花 5~8 分钟，个人用完全够。
> 这一步产出的是**未签名** IPA，签名下一步在你自己电脑上做。

---

## 第 3 步：Windows 装 Sideloadly（约 5 分钟）

1. 打开 https://sideloadly.io ，下载 Windows 版并安装
2. 如果提示缺少 **iTunes / Apple 移动设备驱动**，按它的提示装（Sideloadly 官网有单独驱动包；装了 iTunes 也可以）
3. 装完先别急，见下一步

---

## 第 4 步：签进手机（约 10 分钟）

1. 数据线连上 iPhone，手机上点「**信任此电脑**」，输入锁屏密码
2. 打开 Sideloadly：
   - **IPA 文件**：选第 2 步下下来的 `SavingsTracker.ipa`
   - **Apple ID**：填你自己的 Apple ID 邮箱（免费账号即可）
   - **iDevice**：确认已经识别到你的 iPhone
3. 点 **Start**，弹窗要求输入 **Apple ID 密码**（这是走苹果官方签名，密码只在本机用）
4. 成功后手机上会出现「存款管家」图标，但**现在还打不开**，会提示「未受信任的开发者」：
   - 设置 → 通用 → VPN与设备管理 → 开发者 App → 点你的 Apple ID → **信任**
5. iOS 16 及以上还要：设置 → 隐私与安全性 → **开发者模式** → 打开 → **重启手机** → 重启后确认开启
6. 现在就能打开用了。第一次打开先去「设置」页：填目标金额、目标完成日期、提醒日和时间，然后点保存

---

## 第 5 步：别让它 7 天后打不开（强烈建议做）

免费 Apple ID 签名的有效期是 **7 天**，到期 App 会闪退打不开。两个办法：

**办法 A：AltStore 自动续签（推荐）**
1. 这台 Windows 装 **AltServer**：https://altstore.io
2. 托盘图标右键 → Install AltStore → 选你的 iPhone（需要手机和电脑连同一 WiFi，或插线）
3. 之后只要电脑和手机在同一网络、AltServer 在后台运行，它会自动帮你续签，基本不用管

**办法 B：手动重签**
7 天到了就重复第 4 步，用同一个 Apple ID 重新走一遍 Sideloadly。

> 关键提醒：走第 3、4 步重签时**不要先删掉手机上的 App**，覆盖安装数据还在；一旦删了 App，
> 里面的存款记录会一起没（数据只存在手机本机，没有云端同步）。
> 所以建议每个月去「设置」页点一次「复制数据」，粘到备忘录里存一份。

---

## 后面想加主屏幕小组件时

小组件需要 App Group，免费签名拿不到，得开通 **$99/年** 的 Apple Developer Program，
再用一次云端 Mac 在 Xcode 里创建 Widget 扩展（代码仓库里已经写好了）。
完整步骤在 [小组件配置步骤.md](小组件配置步骤.md)。在那之前，App 里的一切功能都不受影响。

## 卡住的话看这里

| 现象 | 原因 / 处理 |
|---|---|
| Sideloadly 认不到手机 | 换一根**能传数据**的线；iPhone 上点「信任」；装 Apple 移动设备驱动 |
| 提示 "Unable to install" / 签名失败 | Apple ID 密码错，或在 2FA 弹窗里没点允许；也可能是免费账号设备数已满（一个账号最多 3 台设备、同时 3 个自签 App） |
| App 装上但打不开，提示未受信任 | 回去做第 4 步的第 4 条（信任开发者） |
| iOS 16+ 提示需要开发者模式 | 设置 → 隐私与安全性 → 开发者模式 → 开 → 重启 |
| 提醒收不到 | 设置 → 通知 → 存款管家 → 允许通知；App 内设置页的提醒开关要打开，可以点「发测试通知」试一下 |
| 7 天后闪退 | 免费签名过期，重签（第 4 步）或装 AltStore 自动续签（第 5 步） |
| 数据没了 | 只有删 App 才会丢。以后每月「复制数据」备份一次 |
