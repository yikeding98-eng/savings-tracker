# iOS 主屏幕小组件：配置与安装步骤

代码已经全部写好在仓库里：

| 文件 | 作用 |
|---|---|
| `ios/SavingsWidget/SavingsWidget.swift` | 小组件本体（SwiftUI + WidgetKit，金色主题，小号/中号两种） |
| `ios/SavingsWidget/Info.plist` | 扩展的 Info.plist |
| `ios/SavingsWidget/SavingsWidget.entitlements` | 扩展的 App Group 声明 |
| `ios/Runner/Runner.entitlements` | 主 App 的 App Group 声明 |
| `lib/services/widget_bridge.dart` | Flutter 侧：数据一变就把快照写进 App Group 并刷新小组件 |

**数据通道**：App 每次改动数据 → 写 JSON 到 `UserDefaults(suiteName: "group.com.personal.savingsTracker")` 的 `savings_snapshot` 键 → 调 `WidgetCenter.reloadAllTimelines()`。小组件读同一个键，30 分钟兜底刷新一次。

---

## 为什么不能像普通代码一样直接编进去

两件事必须在 macOS + Apple 开发者账号里完成，绕不过去：

1. **Widget 扩展 target 必须在 Xcode 里创建**。它是项目里独立的一个 target、独立 Bundle ID、独立签名，`project.pbxproj` 里的那套配置没有可靠的手写/脚本方案，硬写出来的东西云端编译一旦失败，你在 Windows 上没法调试。
2. **App Group 需要付费开发者账号（$99/年）**。免费 Apple ID 的描述文件里不含 App Group 授权，签名后这个组容器根本不存在，小组件读到的永远是空 —— 会一直显示「打开存款管家」。换签名器、勾自定义 entitlements 都没用，因为问题出在描述文件里没有这个组。

所以完整路线是：**付费账号 → Xcode 加一次 target → Codemagic 自动签名 → TestFlight 装到自己手机**。最后一步用 TestFlight 而不是侧载，是因为带扩展的 App 用侧载工具签会要求你手动处理两套描述文件，很容易失败；TestFlight 一次搞完，一年有效，还不掉签。

---

## 第一步：Apple 开发者账号里准备好 App Group

（前提：已开通 $99/年 的 Apple Developer Program）

1. 打开 https://developer.apple.com/account → Certificates, Identifiers & Profiles
2. **Identifiers → App IDs**，确认这两个存在并都勾上 App Groups：
   - `com.personal.savingsTracker`（主 App）
   - `com.personal.savingsTracker.SavingsWidget`（小组件，没有就新建一个 App ID）
3. **Identifiers → App Groups** → 新建：`group.com.personal.savingsTracker`
4. 回到两个 App ID，各点 Configure，把这个 App Group 勾上

---

## 第二步：在 Xcode 里创建扩展（需要一台 Mac，租 1 小时就够）

没有 Mac 的话，MacinCloud / MacStadium 按小时租，$1~2/小时，这一节 15 分钟能做完。

1. 在 Mac 上把仓库拉下来，装好 Flutter，然后：
   ```bash
   cd savings_tracker
   flutter pub get
   flutter build ios --debug --no-codesign   # 第一次必须先跑，用来生成 Podfile 和 Pods
   open ios/Runner.xcworkspace               # 注意是 workspace，不是 xcodeproj
   ```
2. 菜单 **File → New → Target…** → 选 **Widget Extension**
3. Product Name 填 `SavingsWidget`，**取消勾选** Include Configuration App Intent 和 Include Live Activity，点 Finish（弹出的 Activate scheme 选 Activate）
4. Xcode 会生成一个 `SavingsWidget` 文件夹，把里面模板生成的文件全部删掉，再把仓库里 `ios/SavingsWidget/` 下的 `SavingsWidget.swift`、`Info.plist`、`SavingsWidget.entitlements` 加进这个 target
   - 加文件时确认 Target Membership 只勾 `SavingsWidget`
5. 选 `SavingsWidget` target → **General**：
   - Minimum Deployments 填 **iOS 17.0**（代码用了 iOS 17 的 `containerBackground`）
   - Bundle Identifier 填 `com.personal.savingsTracker.SavingsWidget`
6. **Signing & Capabilities**：先选 `SavingsWidget` target → + Capability → **App Groups** → 勾选 `group.com.personal.savingsTracker`
7. 再选 `Runner` target → + Capability → **App Groups** → 同样勾选这个组
   - Xcode 会自己生成 `Runner/Runner.entitlements`，内容和仓库里那份一致，用 Xcode 生成的即可
8. 选 `Runner` target → **Build Phases** → 确认有 **Embed Foundation Extensions**（老版本叫 Embed App Extensions），里面有 `SavingsWidget.appex`
9. `Cmd+B` 编译一次，确认没有红色的编译错误
10. 把改动提交回仓库（这一步很关键，云端构建要靠它）

> 这段 Swift 我这边没有 macOS 无法编译验证。如果 Xcode 里报错，把报错行贴回来我改。

## 第三步：Codemagic 自动签名 + TestFlight

1. Codemagic → 你的 App → **Settings → Code signing identities**
   - iOS 部分上传你的 **Distribution Certificate（.p12 + 密码）**
   - 上传对应的 **Provisioning Profile**（App Store 类型，包含 `com.personal.savingsTracker` 和 `.SavingsWidget` 两个 Bundle ID，且带 App Group）
2. 编辑 `codemagic.yaml`，把 `ios-personal` workflow 换成下面这段（原来的 no-codesign 版本先留着，等小组件跑通再删）：

```yaml
workflows:
  ios-testflight:
    name: iOS 带小组件（TestFlight）
    instance_type: mac_mini_m2
    max_build_duration: 90
    integrations:
      app_store_connect: your_api_key_name   # 在 Codemagic 的 Teams → Integrations 里建
    environment:
      flutter: stable
      xcode: latest
      ios_signing:
        distribution_type: app_store
        bundle_identifier: com.personal.savingsTracker
    scripts:
      - name: Get Flutter packages
        script: flutter pub get
      - name: Pod install
        script: |
          cd ios && pod install
      - name: Set up code signing
        script: |
          xcode-project use-profiles
      - name: Build IPA
        script: |
          flutter build ipa --release --export-options-plist=$HOME/export_options.plist
    artifacts:
      - build/ios/ipa/*.ipa
```

3. 构建成功后，App Store Connect → 你的 App → TestFlight 里能看到这个版本，手机装 **TestFlight** App 就能安装使用
   - 第一次要先去 App Store Connect 建一个 App 记录（Bundle ID 用 `com.personal.savingsTracker`），否则 TestFlight 里不会出现

## 装好之后怎么用

1. 打开 App 记一笔（或改一次目标金额），这一步会把数据写进 App Group
2. 回到主屏幕，长按空白处 → 左上角「+」→ 搜索「存款管家」→ 选「存款进度」
3. 小号显示：只有已存金额（一行「已存」标签 + 大号金额），没有进度和其他信息
4. 中号显示：存款总额 + 百分比 + 目标 / 本月已存 / 还差 + 下次提醒日期

## 常见问题

- **小组件一直显示「打开存款管家」**：说明 App Group 没通。检查两个 App ID 是否都勾了 App Group、两个 target 的 entitlements 是否都写了组名、签名用的 profile 是否包含它。
- **改了数据小组件不刷新**：iOS 对刷新频率有限制，App 在前台时的改动会立刻刷新；后台最多 30 分钟一次（代码里就是这么设的）。
- **只想先看看效果**：Xcode 里选中 `SavingsWidget` scheme → Run → 选一个 iOS 17 模拟器，可以直接预览小组件。
