# iOS 主屏幕小组件：从零到桌面上看得见

小组件的**代码已经全部写好**，缺的是两件工程层面的东西：一个 Xcode target、一个 App Group 授权。
这份文档把这两件事拆成你能照着点的步骤，**全程不需要 Mac**（target 由云端脚本自动注入）。

| 已有 | 位置 |
|---|---|
| 小组件本体（SwiftUI + WidgetKit，金色，小号/中号） | `ios/SavingsWidget/SavingsWidget.swift` |
| 扩展的 Info.plist / entitlements | `ios/SavingsWidget/Info.plist`、`SavingsWidget.entitlements` |
| 主 App 的 App Group 声明 | `ios/Runner/Runner.entitlements` |
| Flutter 侧写数据 + 刷新 | `lib/services/widget_bridge.dart` |
| 云端自动注册 target 的脚本 | `ios/scripts/add_widget_target.rb` |

**数据怎么走**：App 里每次改动 → 把 JSON 写进共享容器 `UserDefaults(suiteName: "group.com.personal.savingsTracker")` 的 `savings_snapshot` 键 → 调 `WidgetCenter.reloadAllTimelines()` 让桌面立刻重画。小组件读同一个键，另外每 30 分钟兜底刷新一次。

---

## 第 0 步：为什么企业证书不行

你现在手机上那个是用第三方签名平台的企业证书装的，它能签主 App，但**签不了第二个 Bundle ID、也开不了 App Group**。
小组件必须满足三件事，缺一条就用不了：

1. 有自己的 Bundle ID（`com.personal.savingsTracker.SavingsWidget`）和**自己的描述文件**
2. 两个 App ID 都开 **App Groups**，且描述文件里含这个组
3. 主 App 和扩展都挂上 entitlements

这三条只有**自己名下的 Apple Developer Program（$99/年）** 才能满足。所以路线是：开账号 → 后台配 → Codemagic 打包 → TestFlight 装。

> 顺便说一句：企业证书随时可能被苹果吊销，吊销当天 App 打不开、记录也进不去。所以这次换 $99 账号不只是为了小组件，也是给数据上个保险。

---

## 第 1 步：开通开发者账号

1. 打开 https://developer.apple.com/programs/enroll/
2. 用你平时登录 iCloud 的 Apple ID 登录 → 选 **Individual（个人）** → 填姓名地址、付款 $99
3. 审核通常 1~2 天（有时几小时），通过后会收到邮件，developer.apple.com 里能看到 **Certificates, Identifiers & Profiles**

已有账号的话跳过这步。

---

## 第 2 步：Apple 后台配 App Group（最关键，顺序别乱）

打开 https://developer.apple.com/account → **Certificates, Identifiers & Profiles**。

### 2.1 建两个 App ID

**Identifiers → App IDs**，确认这两个都存在：

| Bundle ID | 用途 |
|---|---|
| `com.personal.savingsTracker` | 主 App |
| `com.personal.savingsTracker.SavingsWidget` | 小组件扩展 |

哪个不存在就点 **+** 新建：选 **App** → Description 随便填 → Bundle ID 填上表里的 → 下面 Capabilities 先不管。

### 2.2 建 App Group

**Identifiers → App Groups** → **+**：

- Description：`存款管家共享数据`
- Identifier：**`group.com.personal.savingsTracker`**（一个字都不能差，代码里写死的就是这个）

### 2.3 把 App Group 挂到两个 App ID 上

回到 **App IDs**，分别点进这两个 App ID：

1. 勾选 **App Groups** 这个 Capability（如果列表里没有 Configure，先 Save 一次）
2. 点 App Groups 后面的 **Configure** → 勾上刚建的 `group.com.personal.savingsTracker` → Continue → Save

> 这一步漏了任何一个，小组件都会一直显示「打开存款管家」。

### 2.4 重新生成两个描述文件

**Profiles** → **+** → 选 **App Store**（不是 Ad Hoc、不是 Development）：

- 第 1 个：App ID 选 `com.personal.savingsTracker`，选你的 Distribution 证书 → 下载，命名 `SavingsTracker_AppStore.mobileprovision`
- 第 2 个：App ID 选 `com.personal.savingsTracker.SavingsWidget`，同一张证书 → 下载，命名 `SavingsWidget_AppStore.mobileprovision`

**如果是先建描述文件、后加的 App Group，一定要回来重新生成一遍**，旧的描述文件里没有这个组。

---

## 第 3 步：把证书和描述文件交给 Codemagic

1. 打开 https://codemagic.io → 你的 App → 左侧 **Settings → Code signing identities**
2. **iOS certificates**：上传 `.p12` + 密码（必须是你后台那张 Distribution 证书导出的）
3. **iOS provisioning profiles**：**两个都上传**（主 App 的和小组件的）

Codemagic 构建时会自动把它们装进构建机、按 Bundle ID 匹配到对应 target。

---

## 第 4 步：App Store Connect（上传要用）

### 4.1 建 App 记录

https://appstoreconnect.apple.com → **我的 App** → **+** → **新建 App**：

- 平台 iOS、名称 `存款管家`、主要语言简体中文
- **套装 ID** 选 `com.personal.savingsTracker`
- SKU 填 `savings-tracker`

截图、隐私政策这些先不用填（内部测试用不到）。

### 4.2 生成 API Key

**用户和访问 → 集成 → App Store Connect API** → **+**：

- 名称：**`savings_key`**（必须叫这个，`codemagic.yaml` 里已经写死）
- 权限：**App 管理员（App Manager）**
- 生成后下载 `.p8`（只给一次），记下 **Issuer ID** 和 **Key ID**

### 4.3 填进 Codemagic

Codemagic → 头像 → **Teams** → **Integrations** → **Developer Portal** → Connect：

- API key name：**`savings_key`**
- Issuer ID、Key ID、上传 `.p8`

---

## 第 5 步：跑构建

1. Codemagic → 你的 app → workflow 选 **`ios-testflight`**（名称是「iOS 带小组件 · 已签名 · 上传 TestFlight」）
2. Start new build
3. 日志里重点看三处：

| 日志关键字 | 含义 |
|---|---|
| `[add_widget_target] 已新增 SavingsWidgetExtension target` | 小组件已经注册进工程 |
| `[add_widget_target] 校验通过：appex 将嵌入主 App` | 嵌入配置写对了 |
| `Publishing` 里出现 `savings_key` 上传成功 | 已经传到 TestFlight |

脚本任何一步失败，它会打印 `失败：xxx` 并以红色退出，**把这一行上下文发我，我改脚本**。

---

## 第 6 步：手机上装 + 加小组件

1. App Store Connect → 你的 App → **TestFlight** → **内部测试** → **+** 添加你自己
2. iPhone 装 **TestFlight**，用同一个 Apple ID 登录 → 安装「存款管家」
3. 打开 App，**先记一笔或改一次目标金额**（这一步才会把数据写进共享容器）
4. 回主屏 → 长按空白处 → 左上角 **+** → 搜索「存款管家」→ 选尺寸：
   - **小号**：只有一行「已存」和大号金额
   - **中号**：当前存款 + 百分比 + 目标 / 本月已存 / 还差 + 下次提醒
5. 加入桌面，完成

> 第一次装进去后如果只看到「打开存款管家」，别慌：回 App 里改一次数据再看，或者删掉小组件重加。

---

## 第 7 步：版本与数据

- **版本一致**：扩展的 `CFBundleVersion` 必须和主 App 相同，否则上传会被拒（`ITMS-90473`）。脚本已经从同一个构建号注入，不用你手动对。
- **数据不互通**：企业签的旧 App 和 TestFlight 新 App 在 iOS 看来是两个 App，数据互相看不到。**装新的之前，先在旧 App 里「设置 → 复制数据（JSON 备份）」，把整段 JSON 存到备忘录**；装好新 App 后进「设置 → 粘贴导入备份」，一键恢复。
- **TestFlight 构建 90 天过期**：到期前在 Codemagic 再点一次构建即可，覆盖安装不清数据。

## 排错表

| 现象 | 原因 / 处理 |
|---|---|
| 构建在 `Register widget extension target` 失败 | 看 `失败：xxx` 那行；多半是文件缺失或 gem 没装上，把日志发我 |
| `No profiles for 'com.personal.savingsTracker.SavingsWidget' were found` | 第 3 步没上传小组件的描述文件，或描述文件是加 App Group 之前生成的（重新生成） |
| `Provisioning profile ... doesn't include signing certificate` | 描述文件里勾的证书和你上传的 p12 不是同一张 |
| 构建成功，桌面搜不到「存款管家」小组件 | App 没装好（TestFlight 还没点安装），或 iOS 版本低于 15 |
| 小组件一直显示「打开存款管家」 | App Group 没通：两个 App ID 是否都勾了组、两个描述文件是否都在加组之后重新生成 |
| 小组件数字不更新 | App 里改动会立刻刷新；纯后台最多 30 分钟一次，这是 iOS 的限制 |
| 手机重启后小组件空白一会儿 | 正常，系统要重新读共享容器 |
